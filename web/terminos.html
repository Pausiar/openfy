Condiciones de uso

Estas condiciones regulan el acceso y el uso de este sitio web y de la aplicación Openfy. Al descargar la aplicación o al utilizar el sitio aceptas estas condiciones en los términos que aquí se indican.

Última actualización: 23 de octubre de 2026

1. Objeto

Openfy es una aplicación Android de código abierto que permite organizar en una biblioteca local las playlists y canciones que el usuario importa mediante enlaces, además de reproducir archivos de audio del propio dispositivo. Este sitio web ofrece información sobre el proyecto y la descarga de su APK oficial.

2. Requisitos técnicos

  • Dispositivo con Android 9 (API 28) o superior.
  • Espacio suficiente para la APK (unos 60 MB) y para el contenido local que quieras importar.
  • Permiso de instalación de aplicaciones de fuentes externas, que debes conceder a tu navegador o gestor de archivos.

3. Licencia del software

El código fuente de Openfy se publica bajo la licencia MIT. Puedes estudiarlo, modificarlo, redistribuirlo y usarlo según los términos de esa licencia.

La APK que se distribuye incluye NewPipeExtractor, bajo la licencia GPL-3.0. Como esa dependencia se enlaza dentro de la aplicación, el binario distribuido se ofrece bajo los términos de la GPL-3.0: cualquiera puede obtener el código fuente completo y Corresponding Source desde el repositorio oficial. El detalle de cada dependencia está en licencias de terceros.

Al usar Openfy te comprometes a:

  • Usar la aplicación de conformidad con la legislación aplicable, incluidas las normas de propiedad intelectual.
  • Respetar los términos de uso de Spotify, YouTube y de cualquier otro servicio del que proceda el contenido.
  • No usar la aplicación para eludir medidas técnicas de protección, DRM o sistemas antipiratería.
  • No usar la aplicación para distribuir, revender o retransmitir contenido protegido.

Openfy no descarga audio protegido, no evita DRM y, cuando el contenido no puede reproducirse legalmente dentro de la app, ofrece la apertura de la aplicación oficial o del navegador.
