Funciones

Todo lo que necesitas.
Nada más.

Openfy hace una cosa bien: dejarte escuchar tu música en Android sin nada más.

Importar por enlace

Pega una URL de YouTube o Spotify y Openfy detecta el tipo automáticamente: playlist, vídeo, álbum o canción. Sin cuentas ni OAuth.

↳ youtube.com/playlist?list=…

Biblioteca local

Busca, filtra por plataforma, ordena, renombra y elimina playlists. Todo se guarda con Room en tu dispositivo.

Reproductor integrado

Cola, shuffle, repeat, mini-reproductor y reproducción en segundo plano con notificación multimedia (Media3 / ExoPlayer).

Audio local

Importa archivos del dispositivo con el selector del sistema y mézclalos en playlists junto a tus referencias importadas.

Export / Import JSON

Exporta tu biblioteca completa —playlists, favoritos, historial y preferencias— a un JSON e impórtala cuando quieras.

Firma oficial verificable

Cada APK se firma con la clave de release del proyecto y publica su huella SHA-256. Puedes comprobar que la que instalas es la oficial.

Verifica la descarga

La APK se firma con la clave de release del proyecto (RSA 4096) y el CI comprueba que el certificado coincide con el publicado aquí antes de subir nada. 

# 1. Comprueba el hash del archivo
sha256sum -c openfy-latest.apk.sha256

# 2. Comprueba quién firmó la APK
apksigner verify --print-certs openfy-latest.apk

# 3. Debe coincidir con la huella publicada en esta web

Transparencia legal

Openfy no descarga audio protegido, no evita DRM, no bloquea anuncios de terceros y no reproduce el contenido completo de Spotify o YouTube sin permisos válidos.

La app reproduce archivos locales del usuario, la demo incluida, previews oficiales cuando un backend autorizado los suministra y streams permitidos. Para el resto, abre la app oficial o el navegador. Ninguna clave de API se distribuye en la APK pública.
