1. Licencia del proyecto

El código propio de Openfy (aplicación Android y sitio web) se publica bajo la licencia MIT. El texto completo está en el fichero LICENSE.

Importante: la aplicación enlaza NewPipeExtractor, que se distribuye bajo la GPL-3.0. La GPL-3.0 es copyleft: al enlazarse dentro de la app, la APK distribuida debe ofrecerse bajo los mismos términos GPL-3.0, con su código fuente completo disponible para quien lo solicite. El repositorio público del proyecto ya cumple esa obligación, por lo que cualquiera puede obtener el Corresponding Source.

En la práctica esto significa que la app y su APK se distribuyen bajo la GPL-3.0 aunque el código propio se publique bajo MIT. Puedes consultarlo en el apartado 3 de las condiciones de uso.

3. Recursos de este sitio web

El sitio web no carga ningún recurso de terceros. No utiliza tipografías externas, ni scripts de analítica, ni reproductores incrustados, ni píxeles de terceros. Las tipografías son las del propio sistema y las imágenes son las del proyecto. Por eso este sitio no instala cookies ni requiere banner de consentimiento.

4. Marcas de terceros
